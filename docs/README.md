# مستندات جامع مهندسی و معماری پارادوکس شاپ (Paradox Shop Documentation)

به پورتال مستندات فنی و مهندسی **پارادوکس شاپ (Paradox Shop)** خوش آمدید. این مستندات پس از ممیزی کالبدشکافی کامل بر روی کدهای مخزن، کانتینرهای داکر، تست‌های خودکار و پایگاه داده در سپتامبر ۲۰۲۶ (شهریور ۱۴۰۵) بازآرایی و بروزرسانی شده است.

## ۴. آرشیو و تاریخچه فازهای توسعه (`docs/phases/`)

مستندات تاریخی، واک‌تروها و پلن‌های هر فاز در پوشه اختصاصی آن فاز بایگانی شده‌اند:
- `docs/phases/phase-0-baseline/`: گزارش انتشار فاز پایه تجارت الکترونیک، پلن‌ها و مستندات هاردنینگ سلری.
- `docs/phases/phase-1-wishlist/`: گزارش انتشار فاز ۱ (علاقه‌مندی‌ها).
- `docs/phases/phase-2-shipping/`: گزارش انتشار فاز ۲ (حمل‌ونقل و لجستیک) و رفع ریسپانسیو ره‌گیری.
- `docs/phases/phase-3-promotions/`: گزارش‌های جامع فاز ۳ (موتور تخفیف، فرانت‌اند مشتری، تسویه‌حساب و پنل ادمین).
- `docs/phases/phase-4-reviews-qa/`: گزارش انتشار فاز ۴ (نظرات، تأیید خرید، پردازش رسانه و پرسش‌وپاسخ).
