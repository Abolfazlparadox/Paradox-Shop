# ممیزی جامع کارایی و عملکرد فنی (Performance Audit) — فاز ۴.۶
**پروژه:** Paradox Shop  
**تاریخ ثبت:** سپتامبر ۲۰۲۶  
**شاخه گیت:** `feature/performance-load-testing`  
**نقش مجری:** Senior Performance Engineer / DevOps & Database Specialist  

---

## ۱. اهداف ممیزی کارایی
این ممیزی با هدف کالبدشکافی فنی لایه‌های نرم‌افزاری (Backend، Frontend، Database، Cache، Message Broker و کانتینرها) به صورت کاملاً علمی و مبتنی بر شواهد سنجش‌پذیر (Evidence-Based) پیش از اعمال هرگونه بهینه‌سازی زودهنگام صورت پذیرفته است.

---

## ۲. متدولوژی و ابزارهای ممیزی
برای انجام این ممیزی از تلفیق ابزارهای زیر استفاده شد:
- **Django Query Instrumentation & Connection Queries:** ممیزی کوئری‌های SQL تولیدشده، تشخیص الگوهای $O(N)$ و N+1.
- **k6 (Grafana):** شبیه‌سازی کاربران همزمان چندمرحله‌ای (Multi-stage Virtual Users: 5, 10, 15, 25 VUs) برای آزمون‌های بار سناریومحور.
- **Docker Stats Runtime Telemetry:** رصد بلادرنگ مصرف CPU، حافظه RAM و I/O کانتینرها.
- **Chrome DevTools MCP:** استخراج متغیرهای حیاتی وب (Core Web Vitals) نظیر TTFB، FCP و رصد حلقه رندرینگ سه‌بعدی Three.js.
- **Pytest Automated Regression:** اجرای ۱۶۷ آزمون جامع برای تضمین سلامت منطق تجاری و محدود ماندن تعداد کوئری‌ها.

---

## ۳. دامنه ممیزی معماری

### ۳.۱ لایه بک‌اند و ORM (Django 5.2 & DRF)
- **مسیر فراخوانی داده‌ها:** بررسی Selectorها، Serializerها و Viewها.
- **فیلترها و مرتب‌سازی:** بررسی وجود شاخص‌های پایگاه داده بر روی فیلدهای فیلتر و سورتینگ (`is_active`, `is_featured`, `created_at`, `base_price`).
- **پیش‌بارگذاری روابط (Eager Loading):** ممیزی رفتار `select_related` و `prefetch_related` در کاتالوگ محصولات، سفارش‌ها و نظرات.

### ۳.۲ لایه پایگاه داده (PostgreSQL 16)
- بررسی زمان اجرای کوئری‌های سنگین (`EXPLAIN ANALYZE`).
- بررسی رفتار تراکنش‌ها و ایندکس‌های اختصاصی.
- ممیزی صفحه‌بندی (Pagination) در ابعاد داده‌های واقعی.

### ۳.۳ لایه حافظه میانی (Redis 7)
- بررسی مکانیزم کش خلاصه نظرات (`review_summary`).
- ارزیابی ریسک‌های Cache Stampede و ابعاد مصرف حافظه.

### ۳.۴ لایه صف وظایف ناهمگام (Celery 5.4 & Celery Beat)
- بررسی وظایف دوره‌ای پاکسازی سبدهای مهمان، لغو سفارش‌های منقضی و اعلان‌ها.
- حصول اطمینان از Idempotency و عدم وجود فراخوانی‌های مسدودکننده (Blocking).

### ۳.۵ لایه فرانت‌اند (Next.js 14 App Router & React 18)
- ارزیابی مصرف CPU کامپوننت سه‌بعدی Penrose Hero (Three.js).
- ارزیابی زمان پاسخگویی اولین بایت (TTFB) و رندر اولیه محتوا (FCP).
- بررسی بهینه‌سازی تصاویر و بسته‌های جاوا اسکریپت.
