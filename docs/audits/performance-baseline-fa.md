# خط مبنای عملکرد اولیه پیش از بهینه‌سازی (Performance Baseline) — فاز ۴.۶
**پروژه:** Paradox Shop  
**تاریخ اندازه‌گیری:** سپتامبر ۲۰۲۶  
**محیط آزمون:** Docker Compose (توسعه و ایزوله محلی)  
**سخت‌افزار میزبان:** AMD Ryzen 7 / Intel Core i7 (8 Cores), 16GB RAM, NVMe SSD  

---

## ۱. شرایط و محیط اندازه‌گیری خط مبنا
تمام معیارهای خط مبنا (Baseline) قبل از اعمال هرگونه تغییر یا بهینه‌سازی روی کد ثبت شده‌اند. وضعیت داکر در زمان شروع:
- کانتینرهای فعال: `shop_backend`, `shop_frontend`, `shop_postgres`, `shop_redis`, `shop_celery_worker`, `shop_celery_beat`
- حجم داده تستی اولیه: ۱۶ محصول با واریانت‌ها، تخفیف‌های فعال، دسته‌بندی‌های چندسطحی، ۵ سفارش و ۱۰ نظر.

  - **FCP (First Contentful Paint):** ۱,۱۰۴.۰ میلی‌ثانیه
- مسیر صفحه اصلی (`/`):
  - **TTFB:** ۲۲۵.۰ میلی‌ثانیه
