# راهنمای جامع و نتایج آزمون‌های بارگذاری (Load Testing Report) — فاز ۴.۶
**پروژه:** Paradox Shop  
**ابزار تست:** Grafana k6 (اجرا در قالب کانتینر ایزوله متصل به شبکه داکر)  
**شاخه:** `feature/performance-load-testing`  

---

## ۱. معماری و سناریوهای تست بار
کلیه اسکریپت‌های آزمون بار در پوشه `performance/load-tests/` مستقر شده‌اند:
1. `public-api.js`: شبیه‌سازی ترافیک کاربران عادی بر روی کاتالوگ، لیست محصولات، جزئیات، درخت دسته‌بندی، خلاصه نظرات، روش‌های ارسال و تخفیف‌ها.
2. `catalog-flow.js`: شبیه‌سازی پیمایش کاربر در کاتالوگ (درخت دسته‌ها -> محصولات برگزیده -> جستجوی کاتالوگ -> صفحه محصول -> نظرات).
3. `cart-flow.js`: شبیه‌سازی چرخه حیات سبد خرید مهمان (دریافت سبد، افزودن آیتم، تغییر تعداد، حذف آیتم).
4. `authenticated-api.js`: شبیه‌سازی تعاملات کاربر واردشده (لاگین و دریافت توکن JWT، سبد خرید، لیست علاقه‌مندی‌ها، تاریخچه سفارشات، پروفایل کاربری).

## ۳. نحوه اجرای آزمون‌ها در محیط محلی و داکر
کلیه آزمون‌ها بدون نیاز به نصب سراسری k6 و از طریق Docker با دستورات زیر قابل بازتولید هستند:

```bash
# ۱. آزمون کاتالوگ عمومی
Get-Content performance/load-tests/public-api.js | docker run --rm -i --network paradox-shop_default -e BASE_URL=http://backend:8000 grafana/k6 run -

# ۲. آزمون پیمایش کاتالوگ
Get-Content performance/load-tests/catalog-flow.js | docker run --rm -i --network paradox-shop_default -e BASE_URL=http://backend:8000 grafana/k6 run -

# ۳. آزمون سبد خرید
Get-Content performance/load-tests/cart-flow.js | docker run --rm -i --network paradox-shop_default -e BASE_URL=http://backend:8000 grafana/k6 run -

# ۴. آزمون کاربر لاگین‌شده
Get-Content performance/load-tests/authenticated-api.js | docker run --rm -i --network paradox-shop_default -e BASE_URL=http://backend:8000 grafana/k6 run -
```
