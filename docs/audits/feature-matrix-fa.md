# ماتریس جامع وضعیت و میزان تکامل قابلیت‌های پارادوکس شاپ (Feature Completeness Matrix)

> **منبع حقیقت**: بررسی کالبدشناختی کدهای بک‌اند، فرانت‌اند، کانتینرهای در حال اجرای داکر، دیتابیس PostgreSQL و نتایج ۱۹۰ تست خودکار.  
> **آخرین بروزرسانی**: سپتامبر ۲۰۲۶ (بر روی شاخه فعال `feature/reviews-and-qa`)

وضعیت‌های استاندارد ارزیابی:
- `COMPLETE`: پیاده‌سازی کامل در بک‌اند، دیتابیس، فرانت‌اند، پنل ادمین، تست‌های خودکار و محیط زمان اجرا.
- `PARTIAL`: پیاده‌سازی در بخش‌هایی از سیستم انجام شده اما بخشی از فرانت‌اند یا پنل ادمین متصل نیست یا نیازمند توسعه بیشتر است.
- `UI_ONLY`: صرفاً ظاهر کاربری بدون اتصال به API واقعی یا با داده‌های ماک.
- `BACKEND_ONLY`: پیاده‌سازی در سطح بک‌اند و تست‌ها تکمیل شده اما رابط کاربری فروشگاه برای آن پیاده‌سازی نشده است.
- `MOCKED`: قابلیت با شبیه‌ساز یا ماک کار می‌کند (نظیر درگاه پرداخت تستی).
- `BROKEN`: کد پیاده‌سازی شده اما با خطای زمان اجرا مواجه می‌شود.
- `PLANNED`: صرفاً در نقشه راه یا مستندات ذکر شده و هنوز پیاده‌سازی نشده است.
